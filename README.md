# Doceria Flor de Cacau (demo)

## Como editar
- **Todo o conteúdo** (nome, WhatsApp, mensagens, produtos, passos, FAQ, sobre, contato) fica em `src/data/site.ts`. O arquivo é comentado.
- **Imagens**: substitua os arquivos em `public/images/` mantendo os nomes (`hero.jpg`, `sobre.jpg`, `produto-1.jpg` … `produto-8.jpg`). Use JPGs leves (até ~150 KB).

## Como publicar
No Lovable, clique em **Publish** (canto superior direito). Para domínio próprio: Settings → Domains.
